# Здоровье — план и дневник

Офлайн-приложение (PWA): дневник веса и боли, питание, тренировки без нагрузки на колени, прогресс. Профиль (возраст, рост, вес, цель) вводится в самом приложении — личных цифр в коде и в этом файле нет.

Ни одного внешнего файла и библиотеки: один `index.html` со всем кодом, стилями и данными. Работает без интернета.

## Живая версия

- Приложение: **https://pimplebattletoad.github.io/zdorovye/**
- Репозиторий: **https://github.com/PimpleBattleToad/zdorovye**

Открыть ссылку на телефоне в Chrome → меню ⋮ → **Установить приложение**. Дальше иконка на рабочем столе, офлайн, данные на телефоне.

Обновление после правок: `git push` → в `sw.js` поднять номер `CACHE = 'zdorovye-v3'` → `v4` → закрыть приложение и открыть дважды.

## Как открыть

1. Двойной клик по `index.html` — откроется в браузере. Всё уже работает.
2. На телефоне — см. раздел «Как открыть на телефоне».

Данные хранятся в самом браузере (localStorage, ключ `zdorovye.v1`). Никуда не отправляются. Очистка данных сайта в браузере = потеря записей, поэтому раз в месяц делай **Дневник → Экспорт** (файл JSON).

## Профиль и цифры

Приложение не знает о тебе ничего, пока ты сам не введёшь. Всё личное — в одном месте: **План → карточка «План»** (первая на вкладке):

| Поле | Значение |
|---|---|
| Возраст, лет | для BMR по формуле Миффлина — Сан Жеора |
| Рост, см | то же |
| Стартовый вес, кг | точка отсчёта, от неё считается «сброшено» |
| Цель, кг | линия на графике и прогноз недель |
| Пол | разница в формуле: `+5` для мужчин, `−161` для женщин |
| Дата старта | номер дня плана |

Из них автоматически считается всё остальное — правки в полях сразу пересчитывают дневник:

- `BMR = 10·вес + 6,25·рост − 5·возраст + (пол)`
- `TDEE = BMR × 1,25`
- калории = TDEE × 0,83 (дефицит ~17%), минимум 1500 ккал для мужчин и 1200 для женщин
- белок = 2,0 г на кг «сухой» массы (рост − 97, не меньше 45 кг)
- жиры 28% калорий, остальное — углеводы (не меньше 60 г)

Пока профиль не подтверждён, на вкладке «Сегодня» висит напоминание, а в шапке нет личных цифр. Ничего из этого не уходит в код, в репозиторий и в интернет — только в localStorage твоего браузера.

Формулы дают гипотезу, а не приговор: реальный темп проверяется по весу за 2 недели.

## Как открыть на телефоне

Три способа. Они не взаимоисключающие: можно смотреть на ПК и на телефоне, но **у каждого устройства своя копия данных** — перенос только через **Экспорт** → **Импорт файла**.

### А. По Wi-Fi, за 2 минуты (посмотреть и повводить)

1. На компьютере — двойной клик по `Запустить.cmd`. Откроется окно, в нём два адреса:

   ```
   PC:      http://127.0.0.1:8766/
   Phone:   http://192.168.x.x:8766/   (same Wi-Fi)
   ```

   Первый — для компьютера, второй — для телефона.
2. Телефон и компьютер — в одной Wi-Fi (не «гостевой»).
3. В Chrome на телефоне ввести адрес из строки `Phone:` в адресную строку.

Что не работает в этом режиме: иконку на рабочий стол не поставить (Chrome не считает `http://192.168...` безопасным адресом — поэтому нет ни установки, ни офлайн-кэша). И компьютер должен быть включён с запущенным окном сервера.

Если Windows спросит про сеть — разрешить доступ для **частных сетей**. Адрес меняется при смене сети или после перезагрузки роутера — смотри его в окне сервера.

Если телефон страницу не открывает, дело почти всегда в брандмауэре. Один раз в PowerShell **от имени администратора**:

```powershell
New-NetFirewallRule -DisplayName "Zdorovye 8766" -Direction Inbound -Protocol TCP -LocalPort 8766 -Action Allow
```

Ещё условие: телефон и компьютер в одной сети (не «гостевая» Wi-Fi и не мобильный интернет на телефоне).

### Б. Настоящее приложение: иконка, офлайн, без компьютера (GitHub Pages)

Нужен аккаунт GitHub и 5 минут один раз. Личных данных в репозитории нет — только приложение.

1. github.com → **New repository** → имя `zdorovye`, тип **Public** → **Create repository**.
2. На странице репозитория — ссылка **uploading an existing file** → перетащить `index.html`, `manifest.json`, `sw.js`, `icon.svg`, `icon-192.png`, `icon-512.png` → **Commit changes**.

   `Запустить.cmd`, `README.md` и папку `sync/` загружать не обязательно.
3. **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–3 минуты открыть `https://<логин>.github.io/zdorovye/` — **с корня**, не с `index.html`.
5. В Chrome на телефоне: меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

Дальше приложение открывается как обычное, работает офлайн, хранит данные на телефоне.

Обновление после правок: загрузить новый `index.html` (Add file → Upload files), в `sw.js` поднять номер `CACHE = 'zdorovye-v3'` → `v4`, затем закрыть приложение и открыть дважды.

### В. Только телефон, без компьютера и без хостинга

Открыть `index.html` из файлового менеджера в Chrome (`file://`). Приложение заработает, но иконки не будет, а записи на `file://` Chrome может чистить — как основной способ не советую, только «посмотреть».

## Как поставить как приложение на компьютере (иконка на экране)

Установка PWA работает только по `https` или `localhost` — на `file://` и по Wi-Fi (`http://192.168.x.x`) кнопки «Установить» не будет.

Локально на компьютере:

```powershell
cd "C:\Users\Zerg\Documents\deepseek-harness\Здоровье"
python -m http.server 8765 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8765/` — Chrome предложит установить приложение. (Или просто `Запустить.cmd` — там свой сервер на 8766.)

Обновление установленного приложения: страница грузится «сеть → кэш», поэтому свежая версия прилетает сама при наличии интернета; офлайн остаётся последняя сохранённая. Если телефон упорно держит старый кэш — закрыть приложение и открыть дважды, либо в `sw.js` поднять `CACHE = 'zdorovye-v2'` → `v3`.

## Данные из часов и весов

Ручной импорт: **Дневник → Импорт файла** — CSV/JSON с колонками `date;weight;steps;sleep;kcal;protein;water;beer;pain`.
Понимает запятую как разделитель дробной части, даты `23.11.2026 / 2026-11-23 / 11/23/2026`, сон в минутах, воду в литрах.

Полу-автомат: положить `data.json` рядом с `index.html` (образец — `sync/data.example.json`), запустить **`Запустить.cmd`** и открыть `http://127.0.0.1:8766/` — приложение само забирает `data.json` при каждом открытии. То же работает и с телефона по Wi-Fi-адресу, и на любом сайте по `https`: данные подтягиваются сами, кнопка **Дневник → Подтянуть data.json** делает это вручную.

Как выгрузить данные из Amazfit T-Rex 2 и весов Xiaomi Mi Scale 2 — `sync/README.md`, а для Android пошагово — `sync/android.md` (openScale для весов, Health Connect для шагов и сна).

## Файлы

- `index.html` — всё приложение (разметка, стили, логика)
- `manifest.json` — параметры PWA
- `sw.js` — офлайн-кэш (network-first для страницы, cache-first для иконок)
- `icon.svg`, `icon-192.png`, `icon-512.png` — иконки
- `Запустить.cmd` — локальный сервер + открыть в браузере (для авто-подхвата и установки)
- `sync/serve.ps1` — тот же сервер отдельно; `sync/README.md` — импорт и мосты из Zepp/Xiaomi; `sync/data.example.json` — образец
- `shots/` — скриншоты вкладок (для проверки вида)

## Медчасть и границы

Приложение — не диагноз и не лечение. До нагрузок нужен ортопед/травматолог; при храпе и сонливости днём — исключить апноэ сна. Всё, что ниже 6/10 по боли, — можно; 4–5 — снижаем; 6 и выше — стоп и к врачу.

Стоп-правило: «Остановись немедленно и обратись к врачу, если: боль острая, стреляющая; отек/покраснение/жара в суставе; колено щёлкает с болью; хромота; боль не проходит за 48 ч покоя; боль в покое/ночью».
